# BioRaznoobrazie

Проект по кроссплатформенной разработке на тему «Биоразнообразие» — каталог биологических видов на данных [GBIF Species API](https://api.gbif.org/v1/species/search).
Реализован на Kotlin Multiplatform (Compose Multiplatform) и собирается под 3 таргета: веб, Android, десктоп.

## Возможности

- Список таксонов с бейджами рангов и бесконечным скроллом (постраничная загрузка с сервера, по 50 записей)
- Экран детали таксона: полное научное название, число потомков, описание (грузится отдельным запросом, очищается от HTML)
- Навигация по дереву таксонов любой глубины через экран дочерних таксонов
- Поиск по научному названию с дебаунсом и отменой предыдущего запроса
- Обработка сетевых ошибок: «Нет соединения», «Таймаут», «Не найдено», «Ошибка сервера» с кнопкой «Повторить»
- Ошибка докрутки списка не сваливает экран — рисуется футером с повтором
- Светлая и тёмная темы, переключение языка интерфейса (ru/en)

## Архитектура

Код разделён на слои, зависимости сходятся к domain:

```
API-клиент (Ktor) - Репозиторий - ViewModel (StateFlow) - экран
```

- **domain** — модели предметной области (`Taxon`, `TaxonPage`, `Rank`) и интерфейс `TaxonRepository`, от сети не зависят
- **data** — API-клиент `GbifApi`, DTO с `@Serializable`, мапперы DTO - домен, реализация репозитория; разбор ответа выполняется на `Dispatchers.Default`
- **ui** — экраны как чистые функции `(state, onIntent)`, состояние наружу через `StateFlow`, решения принимает ViewModel

## Запуск

```bash
./gradlew :desktopApp:run                        # запуск на десктопе
./gradlew :webApp:wasmJsBrowserDevelopmentRun    # запуск в браузере
./gradlew :androidApp:assembleDebug              # сборка Android
```

## Проверки

```bash
python tools/check-strings.py    # проверка локализации
```

## Источник данных

[GBIF Species API](https://api.gbif.org/v1/species/search) — открытый API Global Biodiversity Information Facility, ключ не требуется. Постраничная выдача параметрами `limit`/`offset`, поиск по подстроке параметром `q`, иерархия через `highertaxonKey`.
